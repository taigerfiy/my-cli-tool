# 竞彩文档统一格式规范（v1，261117）

目标：以年为单位的赛道，输入文档必须机器可解析、可 diff、可版本化。**Markdown 是唯一源格式**，PDF/在线文档只作历史归档。

## 1. 格式与编码

- 唯一输入格式：`.md`，UTF-8 无 BOM，LF 换行。
- 云盘业务目录（001/008/009/014/015/017…）只保留 `.md`；原件（PDF、在线文档）转完后统一移入「回收站」，保留可回溯性。
- 一份源文件对应一份同名 `.md`，不做合并、不拆卷、不改名。

## 2. 文件命名

- 沿用历史业务名：`YYMMDD + 周X + 内容类型`，例如 `261117周二7表格.md`、`261117周二历史战绩.md`。
- 不加日期前缀、不加版本后缀（版本靠 git / 云盘历史版本管理）。
- 历史笔误名（如 `1261106周五7表格`）**保持原样**，避免破坏既有引用。

## 3. 文档内部结构

```
# <YYMMDD周X><文档类型>          ← 唯一 H1

## 表格1：赔率汇总表             ← 每张表一个 H2，标题沿用原文
| 竞彩场次序号 | 订单日期 | 赛事类型 | 主队 | 客队 | 比赛日期与时间 | … |
| :--- | … |
| 周二001 | 2026-11-17 | 国际友谊赛 | 新加坡 | 巴西 | 2026-11-17 18:00 | … |
```

硬性约定：

1. 每张表必须是 GFM 表格，禁止把单元格压成一整行文本。
2. 前 6 列固定：`竞彩场次序号 / 订单日期 / 赛事类型 / 主队 / 客队 / 比赛日期与时间`；指标列紧随其后，列名取源表头。
3. 数值**原样保留**：小数位数、`万欧/亿欧`、`次/球`、`A胜B平C负`、`+1球：1.64 / 3.45 / 4.20` 一律不改写、不四舍五入、不换单位。
4. 缺失值写 `-`；未开盘写 `该玩法暂未开`；源表未渲染时写 `未渲染`。
5. 表格之外的说明句（"注：…""至此…提取完毕"）单独成行，不得混入数据行。
6. 报告类文档（Step1–Step5、联赛总结、复盘）同样用 MD：H1 标题 + 分节 H2，结论与数据表分离。

## 4. 入库前的保真闸门

每份产物必须通过数字多重集校验：源文件与 `.md` 的 `\d+(?:\.\d+)?` 计数必须完全相等，缺一个即拒收，且**原件不得归档**。校验脚本：`skills/drive-doc-to-md/scripts/gate.py`。
