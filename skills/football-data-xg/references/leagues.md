## 赛季代码

`mmz4281/{season}/` 中的 season 是**两位起始年 + 两位结束年**：

- `2627` = 2026-27（当前赛季）
- `2526` = 2025-26
- `2425` = 2024-25

跨年赛季一律跨两个年份；单年赛季（如部分北欧联赛）用 `2026` 形式，路径同样在 `/mmz4281/` 下，按站点实际为准。

## 关键字段

| 字段 | 含义 | 备注 |

| `HS/AS`、`HST/AST` | 射门 / 射正 | |

| `HF/AF`、`HY/AY`、`HR/AR` | 犯规、黄牌、红牌 | |
| `AHh` | 亚盘让球线 | **负值 = 主队让球**；与 8BO 的 `let`（正值 = 主队让球）符号相反 |

| `B365AHH/AHA`、`AvgAHH/AHA` | 亚盘两边水位 | 可做水位分布分析 |

## 抓取注意

- **必须用 curl + 浏览器 UA**：Python urllib 直连会返回 000 或被拒。
- 站点偶发超时（尤其 `I1.csv`），脚本内置 3 次重试；仍失败就等几分钟重跑。
- 文件是 UTF-8 with BOM，读取用 `encoding="utf-8-sig"`。
- 日期格式 `dd/mm/yyyy`，解析用 `%d/%m/%Y`。
- 该源只含**已赛**轮次，无未来赛程。

## 队名映射维护

脚本内 `TEAM_CN` 字典已覆盖五大联赛约 90 支球队。升降级后新队会以英文原名输出，不会报错。遇到需要补的队，直接在字典里加一行 `"English Name": "中文名"` 即可，不要用模糊匹配（易把不同队串到一起）。

与 8BO 对照时，脚本另有 `BO_ALIAS`（8BO 全称 → 简称），目前含：曼彻斯特城→曼城、曼彻斯特联→曼联、托特纳姆热刺→热刺、巴伦西亚→瓦伦西亚、RB莱比锡→莱比锡红牛。
