# 017 文档模板与字段口径

本文件是两份产出 md 的固定格式基准，与云盘 017 既有文档逐字对齐。渲染脚本 `scripts/render_lineup_md.py` 按此模板出稿，手改时不得改动列头与层级。

## 覆盖边界

只采集 **五大联赛（英超/西甲/意甲/德甲/法甲）+ 欧冠 + 欧罗巴**。其余赛事（欧协联、各国次级、国内杯赛、国家队、友谊赛）不进 017 台账；整批遇到非覆盖赛事时在文末单列「不在采集范围」，不用相似球队补位。

## 一、主表：首发阵容数据

文件名：`{赛季}{联赛}第N轮首发阵容数据.md`（例：`2026-2027英超第十轮首发阵容数据.md`）

结构：

```markdown
# {赛季}{联赛}第N轮首发阵容数据

# {联赛}联赛首发阵容与基础数据汇总 (MM-DD 至 MM-DD)

## N. 主队 比分 客队 (MM-DD HH:MM)

### 主队 (阵型)

教练: X | 首发身价: X亿欧 | 平均身高: Xcm | 平均年龄: X岁

|位置|号码|球员|
|-|-|-|
|门将|1|球员|
|后卫|3|球员|
|...|...|...|

### 客队 (阵型)

教练: X | 首发身价: X亿欧 | 平均身高: Xcm | 平均年龄: X岁

|位置|号码|球员|
|-|-|-|
|门将|1|球员|
|...|...|...|
```

### 字段口径

- 场次头：序号、主队、比分、客队、开赛时间（北京时间 `MM-DD HH:MM`）。
- 每队一节：队名 + 阵型；下一行教练/身价/身高/年龄四项，缺项写「未提供」。
- 首发表固定三列 `位置|号码|球员`，每队 11 行；号码缺写 `-`，不补造。
- 身价/身高/年龄照抄截图原始数字，不改写单位与精度。

### 位置词表（固定，不自造）

`门将` / `后卫` / `中卫` / `翼卫` / `后腰` / `中场` / `前场` / `攻击型中场` / `前锋`。

按阵型归位：
- 4-2-3-1：门将 1、后卫 4、后腰 2、前场 3、前锋 1。
- 3-4-2-1 / 3-4-3：门将 1、中卫 3、翼卫 2、中场 2、攻击型中场/前场 2、前锋 1。
- 官网分组与截图站位冲突时，以官网位置分组为准，分歧记入补充表备注。

## 二、补充表：首发补充数据

文件名：`{赛季}{联赛}第N轮首发补充数据.md`

结构：

```markdown
# {赛季} {联赛}第N轮 首发补充数据（AI赛后补录）

本文件为「{赛季}{联赛}第N轮首发阵容数据」的补充字段（伤停/替补调整/发挥好/发挥差）。原始首发数据来自用户截图，经权威源交叉核对；此处只记录事实不分析。
补录时间：YYYY-MM-DD | 来源：...

## 第N场 主队 比分 客队 (MM-DD)

### 主队

- 伤停/缺阵：...
- 替补调整：分钟 下X 上Y；...
- 发挥好：球员（事实：进球/助攻/扑救/解围等）
- 发挥差：球员（事实：送点/失误/染黄/错失良机等）

### 客队

- 伤停/缺阵：...
- 替补调整：...
- 发挥好：...
- 发挥差：...

---
## 口径与待核备注

- 进球：...
- 黄牌：...
- 译名/阵型分歧：...
```

### 补充口径

- **只记事实，不分析**：不写「士气/底蕴/状态火热」等主观判断，不给方向与投注建议。
- 伤停三分类：确定（伤）、存疑、停赛（红牌/累积黄牌）；原文照录伤情部位。
- 替补调整格式：`分钟 下X 上Y`，多人用分号分隔；只知换人不知换上者写 `分钟 X下（上未提供）`。
- 发挥好/差：挂到具体球员，括号内写可核验事实（分钟+事件）；无内容写 `-`。
- 截图未提供的伤停、评价，标「未提供」，不用印象补填。

## 三、命名与归档

- 赛季/轮次/联赛名以用户批次说明为准；多轮次或多联赛按卷拆分，单份正文 ≤20 页。
- 产出先在本地出 md 草稿交用户确认；归档 017 云盘目录（`BCKZfCB2xlwDccdpgWYcMwP6nob`）在用户确认后执行，上传前核对同名去重。
- 本 skill 只产出 md，不直接写 Base1 轮换台账/球员档案/017 情报表；入库由后续流程负责。

## 四、输入 JSON（渲染脚本）

`scripts/render_lineup_md.py` 读取的结构化 JSON 字段见 `assets/sample_match.json`：

- 顶层：`season / league / round / report_range / supplement_note / matches[] / notes[]`
- 每场：`no / home / away / score / kick / home_team / away_team`
- 每队：`name / formation / coach / value / height / age / starters[] / injuries / subs / good / bad`
- 首发：`pos / num / name`，必须 11 人；不足 11 脚本打 ⚠ 警告。
