# 在线核对数据源分级与可达性

截图是原始数据源；本文件记录完赛后在线核对可用的源、字段覆盖与已验证做不通的通道，避免重复踩坑。核对顺序从一级到二级，截图缺的字段（换上者、伤停、评价）从权威源补；源间分歧写入补充表「口径与待核备注」。

## 一级源（可单独确认首发）

| 源 | 通道 | 可取字段 | 备注 |
|---|---|---|---|
| 联赛官网 lineups（如 premierleague.com） | web.fetch | 首发 11、号码、位置分组、阵型、教练、替补、换人分钟、进球/助攻、黄牌 | 五大联赛/欧战首选；页面 JS 渲染但 lineups 段可被 fetch 透出 |
| 俱乐部官网战报 | web.fetch / general_search | 首发+号码、替补名单、伤停公告、教练 | 与联赛官网互证；伤停以官网赛前公告为准 |

## 二级源（需两源一致才确认）

| 源 | 通道 | 可取字段 | 缺口 |
|---|---|---|---|
| ESPN summary API | `site.api.espn.com/apis/site/v2/sports/soccer/<slug>/summary?event=<id>`，curl/JSON | starter 布尔标记、号码(jersey)、细分位置缩写、bench、换人分钟 | 教练/身价/年龄/身高常为 null；联赛 slug 需先定位 |
| 出奇体育 live-lineup | curl 直连 HTML（GBK/UTF-8） | 首发 11（HTML 属性含 playerid/号码/位置标签）、教练、阵型、全队身价、平均年龄、替补号码位置、伤停 | 无平均身高、细分位置；首发号码位置在 HTML 属性，文本层可能不透出 |
| 懂球帝战报 | web.fetch | 换人上下者+分钟、进球/助攻、首发名单中文译名 | lineup 公开页字段薄、可能滞后；以战报正文为准 |
| WhoScored Confirmed Lineups | web.fetch | 首发+号码、替补名单、阵型 | 阵型口径与他源偶有分歧；无身价年龄 |
| UEFA 官网 lineups | web.fetch | 欧战/国家队大名单、教练、年龄、国籍、场次进球 | 不区分首发/替补；首发需另源 |

## 已验证做不通（勿重复尝试）

| 源 | 现象 |
|---|---|
| Transfermarkt | 202 / JS 机器人验证，curl 与 web.fetch 双通道被拦；身价/年龄/身高/个人身价拿不到 |
| FBref | 403 Cloudflare「Just a moment」 |
| Sofascore | API 403 Forbidden |
| Eurosport | curl 403，web.fetch 名单残缺 |
| 竞彩官网 | 对阵详情只给赛季出场统计，无首发；异步加载 |
| 懂球帝 lineup 页 | JS 渲染，仅透出姓名，号码/位置/名单滞后 |

## 截图口径提醒

- 500 体育（500万网）页面区块常标「预计阵容」，属媒体预测；完赛后部分场次回写实际首发。**入库前必须与一级源互证**，赛前预计名单不得当赛后确认首发。
- 截图图标：足球=进球，黄牌/手势=染黄，L 箭头+分钟=被换下；助攻图标需结合战报文字确认。
- 队名/球员名以 Base1 名称对照表（`tblisjWesOVwl2We`）归一；查不到保持截图原名并在备注标译名分歧，不猜译名。

## 核对清单（每场逐项过）

1. 首发 11 人名单与号码：截图 ↔ 联赛/俱乐部官网一致。
2. 阵型、教练：两队分别核对。
3. 换人：分钟、下者、上者三要素齐全；截图只有下者时，从战报补换上者。
4. 进球/助攻/黄牌：以官网事件流为准，截图图标不符记入备注。
5. 伤停/缺阵：官网赛前公告或二级源汇总，区分伤/存疑/停赛。
6. 身价/身高/年龄：照抄截图；在线源不覆盖时保留截图值，不另算。
