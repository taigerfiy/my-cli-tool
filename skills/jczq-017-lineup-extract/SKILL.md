# 017首发提取

## 定位

半手工、半自动化的 017 首发台账录入窗口：用户按轮次提供原始阵容截图，本 skill 负责读图提取、在线核对、按固定模板出两份 md。不做比分/赔率预测，不给方向判断。

覆盖边界与轮换台账一致：**英超/西甲/意甲/德甲/法甲 + 欧冠 + 欧罗巴**；其余赛事不采集，见 [references/format-template.md](references/format-template.md) 覆盖边界段。

## 协作流程

1. **接单**：接收截图 + 批次说明（联赛/赛季/轮次/开赛日期、竞彩编号或对阵）。一场一图或一轮多图均可；信息不全先问，不猜场次。
2. **读图提取**：逐队辨认阵型、教练、首发身价/平均身高/平均年龄、首发 11 人（位置/号码/姓名），以及换人箭头分钟、进球/黄牌图标、伤停区块。
3. **在线核对**：按 [references/sources.md](references/sources.md) 源分级，用联赛/俱乐部官网核对首发名单、号码、阵型、教练；补全截图缺失的换上者、进球助攻、黄牌、伤停。源间分歧记入补充表备注。
4. **归一**：队名/球员名过 Base1 名称对照表（`tblisjWesOVwl2We`）；译名分歧保留原名并备注，不猜译。
5. **结构化**：把整理好的场次填成 JSON（schema 与样例见 `assets/sample_match.json`）。
6. **渲染出稿**：跑 `scripts/render_lineup_md.py` 生成两份 md；也可按模板手写，但列头/层级不得改动。
7. **交付确认**：本地 md 草稿交用户过目；确认后再归档 017 云盘目录，上传前同名去重。本 skill 不直接写 Base1 台账表。

## 硬规则

- 缺失字段写「未提供」，**不猜填、不补造**；号码缺写 `-`。
- 补充表**只记事实**（进球/助攻/换人/伤停/染黄/具体失误），不写士气、底蕴、状态评价，不给投注建议。
- 数字不改写：身价/身高/年龄/分钟照抄原始值与单位。
- 赛前「预计阵容」不得当赛后确认首发；完赛名单必须经一级源互证。
- 每队首发必须 11 人；脚本不足 11 会打 ⚠，需回查截图或在线源补齐。
- 纯 Markdown 交付（UTF-8/GFM 表格），不做 docx 镜像。

## 脚本

```bash
python3 scripts/render_lineup_md.py --input match.json --out-dir ./out
```

输出：`{赛季}{联赛}第N轮首发阵容数据.md`、`{赛季}{联赛}第N轮首发补充数据.md`。
