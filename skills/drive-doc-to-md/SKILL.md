# drive-doc-to-md

把云盘文件夹里的 **PDF / 在线文档(docx)** 一对一转成同名 `.md`，上传回同一文件夹，回读校验通过后把原件移入「回收站」文件夹。

## 什么时候用

- "对云盘 X 文件夹做 md 转化"、"一对一转化"、"转完原件全部移到回收站"
- 竞彩各目录（001 7表格、014 赛果清单、017 首发阵容、008 赔率报告…）的格式迁移
- 只需要"看内容"时不要用本 skill：单份读取用 `lark-cli drive +fetch` / `docs +fetch` 即可

## 铁律

1. **先转换、后归档**：每份文件必须 `convert → gate → upload → 回读校验 → move` 逐份闭环；闸门不过的文件**禁止移动原件**。
2. **闸门是数字级**：`scripts/gate.py` 比对源文件与产物的数字多重集（`\d+(?:\.\d+)?`），缺一个数即 FAIL；多一个也算 FAIL。禁止用"看起来差不多"替代。
3. **一对一命名**：`X.pdf → X.md`，原名照抄（含历史笔误），不重命名、不加日期前缀。
4. **不覆盖用户已有 MD**：同名 `.md` 已存在时先停，报给用户；若两者内容逐字相同（已校验），可只归档原件、不重传。
5. **断点续跑**：状态写在 `work/state.json`，中断后重跑会自动跳过已完成步骤；已移走原件即使重跑也不会重传。
6. **不补写数字**：标题/表头一律照抄原文，自行补的日期、编号会被闸门当成多余数字而 FAIL。

## 执行

```bash
cd <工作目录>
python3 <skill>/scripts/run.py --folder <folder_token或URL> --bin <回收站folder_token> --dry-run   # 先看清单
python3 <skill>/scripts/run.py --folder <folder_token> --bin <回收站folder_token>                 # 正式跑
python3 <skill>/scripts/run.py --folder <folder_token> --bin <回收站> --keep-originals            # 只转不归档
```

常用目录 token 在本地私有配置中维护（公开仓库不写入内部 token）：

| 目录 | token |
|---|---|
| 001_竞彩赛前7表格 | `<folder_token:001>` |
| 014_赛果清单 | `<folder_token:014>` |
| 017_首发阵容 | `<folder_token:017>` |
| 回收站 | `<folder_token:回收站>` |

未指定 `--bin` 时不要猜，向用户确认回收站目录。

## 转换规则（自动路由）

`run.py` 先读 `pdftotext` 文本，按形态选转换器：

| 形态 | 判定 | 转换器 | 处理 |
|---|---|---|---|
| 赛果流水 | 同时含 `全场比分` 与 `半全场` | `convert_results.py` | 一行一场，11 列；五个玩法单元原值保留（`无`、`胜其他 19.00`、`7+(4.50)`） |
| 管道表 | 表中 ≥ 5 行以 `\|` 开头 | `convert_core.py` pipe | 原点就是 Markdown 渲染出的 PDF（017 首发阵容、早期 7表格、历史战绩）；只把断行拼回整行 |
| 叙述条目 | 含 `首发补充数据` 或 `伤停/缺阵` | `convert_notes.py` | H1 标题 + 来源段 + 每场 H2 + 每队 H3 + `- **伤停/缺阵**：…` 条目；40 字硬换行按 CJK 无空格规则合并 |
| 纯文本流 | 其余（无 `\|` 的压平表格） | `convert_core.py` plain | 按 `周XNNN + 日期 + 赛事 + 主 + 客 + 时间` 切列，剩余 token 按众数列数还原 GFM 表 |

拼接规则：先按"空格版"拼、失败再按"无空格版"拼；`次/球`、`万欧/亿欧`、`A胜B平C负`、`%`、`-1球：` 等被断行拆散的片段自动合回同一数值；`---` 分隔线与说明句单独成行。

实测：001 目录 88 份（84 PDF + 4 docx）、014 目录 42 份、017 目录 120 份（28 管道表 + 92 叙述/其他），闸门全部通过。

## 失败处理

| 现象 | 处理 |
|---|---|
| 下载 504 / timeout / 批量拉包限流 | 自动重试 3 次；集中出现时直接重跑 `run.py`，已完的会跳 过、失败的会重试 |
| 闸门 FAIL（数字缺失/多余） | 停在该份，保留原件，输出差异清单；禁止上传残缺 MD，禁止补写数字蒙混 |
| 回读校验 FAIL | 删除刚上传的 MD（`drive +delete`，需用户确认）后重来 |
| 行内出现"未归类残留" | 新表结构出现，需扩充对应转换器，不得直接交付 |
| docx 返回空 | 多为空文档或权限不足，报给用户 |

## 收尾报告
