# drive-doc-to-md

把云盘文件夹里的 **PDF / 在线文档(docx)** 一对一转成同名 `.md`，上传回同一文件夹，回读校验通过后把原件移入「回收站」文件夹。

## 什么时候用

- "对云盘 X 文件夹做 md 转化"、"一对一转化"、"转完原件全部移到回收站"
- 竞彩各目录（001 7表格、014 赛果清单、017 首发、002 进球分布、008 赔率报告…）的格式迁移
- 只需要"看内容"时不要用本 skill：单份读取用 `lark-cli drive +fetch` / `docs +fetch` 即可

## 铁律

1. **先转换、后归档**：每份文件必须 `convert → gate → upload → 回读校验 → move` 逐份闭环；闸门不过的文件**禁止移动原件**。
2. **闸门是数字级**：`scripts/gate.py` 比对源文件与产物的数字多重集（`\d+(\.\d+)?`），缺一个数即 FAIL。禁止用"看起来差不多"替代。
3. **一对一命名**：`X.pdf → X.md`，原名照抄（含历史笔误），不重命名、不加日期前缀。
4. **不覆盖用户已有 MD**：同名 `.md` 已存在时先停，报给用户决定。
5. **断点续跑**：状态写在 `work/state.json`，中断后重跑会自动跳过已完成步骤，不会重复上传/重复移动。
6. **无文本层不猜**：`pdftotext` 取不到正文（App 截图 / 扫描件）时判 `scanned_no_text`，保留原件、不输出空 MD、不归档，交回用户决定。

## 执行

```bash
cd <工作目录>
python3 <skill>/scripts/run.py --folder <folder_token或URL> --bin <回收站folder_token> --dry-run   # 先看清单
python3 <skill>/scripts/run.py --folder <folder_token> --bin <回收站folder_token>                 # 正式跑
python3 <skill>/scripts/run.py --folder <folder_token> --bin <回收站> --keep-originals            # 只转不归档
```

常用 token：

| 目录 | token |
|---|---|
| 001_竞彩赛前7表格 | LGzJfhxfeld4cjdeaDqc0jwxnSb |
| 回收站 | J0sEfHxsGlzvOxdyqnscpoQEnRg |

未指定 `--bin` 时不要猜，向用户确认回收站目录。

## 转换规则（scripts/convert_core.py）

按"表"粒度自动选路：

| 形态 | 判定 | 处理 |
|---|---|---|
| plain | 无 `\|` 的纯文本流 PDF（近期 7表格） | 按 `周XNNN + 日期 + 赛事 + 主 + 客 + 时间` 固定前缀切列，剩余按 token 还原 GFM 表格；列名取表头，取不到则用固定名 |
| pipe | PDF 里本身渲染了 `\|` 表格（早期 7表格、历史战绩） | 只把 PDF 断行拼回整行，保留原有标题层级与管道表格 |

拼接规则：先按"空格版"拼（PDF 单元格之间丢空格时更常见），失败再按"无空格版"拼；中文与中文之间不加空格；`次/球`、`万欧/亿欧`、`A胜B平C负`、`%`、`-1球：` 等被断行拆散的片段自动合回同一数值；`---` 分隔线与"至此…提取完毕"之类说明句单独成行，不混入数据行。

保真率：001 目录 88 份（84 PDF + 4 docx）实测闸门全部通过，含 260901–261117 跨版本表结构差异（表3 有过"近期全维度战绩"/"基础攻防"两种 schema）。

## 002 进球分布与阵型（scripts/convert_goals.py）

一份 PDF 含多场比赛：`A vs B（赛事）` 起头，每场 `进球分布`(球队/总/6 个时段) + 说明句 + `阵型数据`(球队/阵型/胜平负/场均得分/场均进失球，同队第二、三种阵型首列缺队名)。转换输出 `# 文档标题 / ## 场次 / ### 两个小节 + GFM 表`。

三个坑：跨页重复的 `进球分布`/`阵型数据` 标题与表头（按场次分组才不丢）、`---` 分隔线混入数据行、页尾断行的表头残片。兜底 `audit()`：源文件每行都必须有「数字+中文指纹」相同的对应行，对不上的原样进 `## 原文附录`，既不丢数也不造数。

无文本层（App 截图拼成的 PDF，`pdftotext` 只出个位数）一律 `scanned_no_text` 失败并保留原件，不做猜测性 OCR。

## 失败处理

| 现象 | 处理 |
|---|---|
| 下载 504 / timeout | 自动重试 3 次；仍失败只跳过该份，不影响其他 |
| 闸门 FAIL（数字缺失） | 停在该份，保留原件，输出缺失数字清单；禁止上传残缺 MD |
| 回读校验 FAIL | 删除刚上传的 MD（`drive +delete`，需用户确认）后重来 |
| 无文本层 / 扫描件 | 判 `scanned_no_text`，保留原件不归档，报给用户决定是否 OCR |
| docx 返回空 | 多为空文档或权限不足，报给用户 |

## 收尾报告

给用户的汇报固定四项：`目录 / 处理份数（PDF n + docx m）/ 闸门通过数 / 回收站新增数`，并列出任何失败项与原因。不要贴表格明细。
