## 取数约定

按球队过滤，一次一队，不读全表（档案表用 `所属俱乐部` 过滤）：

```bash
lark-cli base +record-list --base-token FsnQbGerEalbfBsmWFScFJtTnwe \
  --table-id tblJiIkjupGhRBia --as user --format json --limit 200 \
  --filter-json '{"logic":"and","conditions":[["球队","==","阿森纳"]]}' \
  --field-id 联赛 --field-id 轮次 --field-id 轮换人数

lark-cli base +record-list --base-token FsnQbGerEalbfBsmWFScFJtTnwe \
  --table-id tbl6o4arP72RKhhL --as user --format json --limit 200 \
  --filter-json '{"logic":"and","conditions":[["所属俱乐部","==","阿森纳"]]}' \
  --field-id 规范名 --field-id 联赛首发率 --field-id 联赛分级
```

- 过滤语法是 `["字段","==",值]`；不能用 `+data-query` 的 conditions 结构（两套语法不通用）
- `--format json` 时 `--limit` 上限 200；返回 `data.fields`、`data.data`（行数组）、`data.record_id_list`，按位对应
- 需要整批导出时用 `--format ndjson --output x.ndjson`（默认上限 10000），但单队查询不要走全表导出
- datetime 读回形如 `2026-11-08T22:00:00.000+08:00`，解析取前 16 位即可
- 单选读回是数组（`["英超"]`），比较前先取第 0 项

## 统计口径

- 场均轮换 = 该队该联赛所有有基线轮次的 `轮换人数` 均值；首轮不计
- 近 3 轮 = 该联赛 `轮次` 最大的 3 行
- 距本场休息 = 本场开赛日 − 该队末轮开赛日（同联赛）；跨赛事不合并
- 欧战穿插 = 该队在本场前 4 天内有欧冠/欧罗巴行
- 全勤核心人数 = 档案表中该队 `联赛分级=全勤核心` 的人数

## 已知坑

1. **队名分裂**：原始 017 里「国米/国际米兰」「尤文/尤文图斯」并存，已用名称对照表（`tblisjWesOVwl2We`，537 条记录、667 条映射、130 别名）归一。新增别名先补对照表，再跑 `scripts/export_alias.py`。
2. **重复写入**：批量接口偶发重试导致同键重复，台账表曾出现 800 条重复。任何写库后必须按主键查 `count_all` 与 `distinct_count`，不相等就按主键去重，禁止无脑重灌。
3. **`+field-update` 会重置定义**：只传 `name`+`type` 改名，会把 `select` 的选项和 `number` 的 `progress` 样式一并冲掉（已踩过：联赛分级选项变空、联赛首发率退回 plain）。重命名选择/数字字段必须同时带上 `options` / `style` 全量定义。
4. **跨赛事必须分列**：同一球员在联赛与欧冠各有一组轮次，若只留一组字段会互相覆盖（国米球员 11 轮被 4 轮盖掉，574 处不一致）。联赛与欧战一律拆成两套字段。
5. **西甲缺口**：R4/R6/R8 共缺 8 行（源文件缺场），不是解析错误；做队级均值时按实际轮次算，不按 12 轮假定。
6. **欧战轮次是月度**：欧冠/欧罗巴的 `休息天数` 约 25–32 天，不能当联赛休息天数引用。
7. **首轮无基线**：R1 的延续/轮换/延续率都是空，别当 0 轮换处理。
8. **缺阵计数是文本切分**：同一球员原文重复可能出现多计；需要精确时读 `伤停原文`。
