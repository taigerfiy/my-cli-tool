# 首发轮换台账

## 解决什么

017 的首发数据是「一场 → 11 人」的纵切，只能回答某场谁上了；本 skill 用「联赛 × 轮次 × 球队」的横向时间序列回答：这支球队换人有多频繁、换在哪个位置、核心谁不可替代、连续几轮零轮换、伤停是累积还是在缓解。

## 口径（固定，不得临时改）

- 延续人数 = 本轮首发 11 人与上一轮重合人数；轮换人数 = 本轮首发 − 延续；延续率 = 延续 / 首发人数
- 休息天数 = 同联赛同队相邻轮次开赛日期差；跨赛事（联赛 ↔ 欧战）不合并计算
- 缺阵三分类：确定（原文未带存疑）、存疑（存疑/成疑/可能复出）、停赛（红牌/累积黄牌）
- 球员四级：全勤核心 ≥80%、常规主力 ≥50%、轮换 ≥25%、边缘 <25%
- 队名以台账 `球队` 字段的规范名为准；竞彩清单里的简称先过 `assets/alias_map.json`，查不到就标「未匹配」，不猜、不用近似名

## 触发口令

| 口令 | 动作 |
|---|---|
| `轮换卡 <日期> <编号…>` | 只对点名的竞彩场次出卡，默认 2–5 场 |
| `轮换卡 全` | 当日竞彩清单全部场次出卡（超过 6 场自动拆卷，每卷 ≤20 页） |
| `台账 <球队>` | 只查该队逐轮明细，出一份纵向表，不出风险评级 |
| `刷新别名` | 重跑 `scripts/export_alias.py`，从 Base1 名称对照表重建 `assets/alias_map.json` |

编号只给后三位；日期是**销售日期**（次日凌晨场仍算当天）。

## 快速开始

```bash
# 1) 竞彩清单（主客队用竞彩原写法）
cat > matches.json <<'EOF'
[{"no":"周三003","home":"阿森纳","away":"切尔西","kick":"2026-11-19 03:30","league":"英超"}]
EOF

# 2) 出卡
python3 scripts/rotation_card.py --matches matches.json --out 261118_轮换风险卡_周三003.md

# 3) 全量当日（超 6 场自动拆卷）
python3 scripts/rotation_card.py --matches day.json --out-dir ./out --max-per-file 6
```

脚本按 `球队` 字段过滤取数（每次 1 队，失败即报错并指出哪队未取到），不读全表；取不到记录时该队整段写「台账无该队记录（017 未覆盖或队名未匹配）」，不填估算值。

## 风险评级（写进卡里，别口头判断）

| 信号 | 加分 |
|---|---|
| 该队该联赛场均轮换 ≥3.0 | +2（≥2.0 记 +1） |
| 距本场休息 ≤3 天 | +2（≤5 天记 +1） |
| 最近 3 轮确定缺阵合计 ≥4 人 | +2（≥2 人记 +1） |
| 本场前 4 天内该队有欧冠/欧罗巴场次 | +2 |
| 最近 3 轮场均轮换 ≤1.5 且 0 轮换 ≥2 次 | −1（稳定性加分，抵扣体能累积） |

合计 ≥5 → **高**；3–4 → **中**；≤2 → **低**。每档必须写依据（哪几项加分），只给结论不给依据视为未完成。

## 输出结构（每场一节）

1. 场次头：编号、主客队、开赛时间、联赛、样本范围
2. 主客对照表：场均轮换 / 近期轮换（最近 3 轮序列）/ 延续率 / 休息天数 / 最近 3 轮确定缺阵 / 存疑名单 / 全勤核心人数 / 近 3 轮 0 轮换次数
3. 不可替代点：每队首发率最高的 3 人（含位置与首发率）
4. 轮换风险点：3–5 条要点，写清「为什么这轮可能被动轮换」——欧战穿插、连续零轮换后的体能拐点、缺阵集中在某条线（后卫/中场/前锋）
5. 评级：高/中/低 + 加分项明细

不写方向判断、不写比分预测、不给投注建议。

## 硬规则

1. 只对竞彩当日场次出卡；不主动给非竞彩场次，也不为凑数扩样本
2. 台账里查不到的队写「台账无该队记录」，不用联赛平均值顶替
3. 样本 <3 轮（如升班马、欧战新队）标 `⚠样本不足`，评级照算但注明
4. 欧冠/欧罗巴轮次按月排，`休息天数` 是「欧战轮次间隔」，不得当成联赛休息天数引用
5. 缺阵人数是文本切分统计，同一球员重复出现可能多计；逐人核对以 `伤停原文` 为准
6. 写库一律不做：本 skill 只有读权限路径；新数据入库走 017 解析流程
